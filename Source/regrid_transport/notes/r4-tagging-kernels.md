# R4: tagging kernels (K2 record)

Files: `rt_tag_kernels.F90` (Fortran), `TagOps.H/.cpp` (C++ loop over boxes), `tests/test_tagging.cpp` (ctest `regrid_transport_tagging`, `regrid_transport_tagging_np4`).

**Kernel style (ADR-001).** K2: Fortran, flat explicit-shape arrays in the AMReX index space, no module data, no I/O. Host build uses `parallel do collapse(2)` with the loop variables and per-cell scalars `private`; offload build (`RT_OFFLOAD`, or `nvfortran -mp=gpu`) uses `target teams distribute parallel do collapse(3)` with `is_device_ptr` (nvfortran) / `has_device_addr` (others) and no `map` of the big arrays, the same pattern as the S4 mass kernels. The offload path was only syntax-checked with gfortran (`-DRT_OFFLOAD`), not run: no GPU compiler run in this step. **No K1 kernel was needed.** The C++ side only loops over boxes and passes pointers; the AMReX tag array (one byte per cell) is passed to Fortran directly as `integer(c_signed_char)`. The clip to the refinable region and the tag count are also Fortran kernels (`rt_tag_copy_box`, `rt_tag_count`).

**Criteria implemented.** `Above`: tag where `v - base > thr` (temperature above ambient, HRRPUV above a level). `Diff`: tag where the largest undivided difference to the 2 (or 4, or 6) face neighbours exceeds `thr`; undivided means no division by the cell size, so a front is refined until its jump is spread over cells. `relative`: each difference is divided by max(|v|, |v_nb|) (density). Species: `v = (rho*Z_i)/rho` from two fields. User boxes and the footprints of static finer `&MESH` entries: `tag_boxes`. Hysteresis (`TAG_KEEP`): cells under the finer level use `thr*keepfac`, others `thr`; the mask comes from `make_covered_mask` (the next finer BoxArray coarsened). Directions with a single cell are switched off with `dirs[d] = 0` and their neighbours are not read (test with poisoned ghost values).

**Tag buffer and nesting** are done by AMReX itself when it builds the grids (`N_ERROR_BUF`, `N_PROPER` are already passed in `make_amr_info`); a test of the buffer through a real regrid belongs to the dynamic-hierarchy step (needs the AmrCore regrid call, see `notes/r4-regrid-wiring.md`).

**Inputs the kernels need from the driver:** the cell field with one valid ghost layer in every active direction (same-level exchange and boundary fill done before tagging, so tags across box and rank edges agree), the field at the end of a full step, and for hysteresis the finer level's BoxArray. Not verified: the HRRPUV field is kept at the end of a step (assumption of the design note); vorticity is not implemented (later, per ruling).

**Determinism.** Tags depend only on cell values and thresholds (no reductions, no order dependence); the unit test gives identical results at 1, 2 and 4 ranks and with 8 OpenMP threads. `-ffp-contract=off` is not set in this step; a threshold decision flips only if a value sits within round-off of the threshold.
