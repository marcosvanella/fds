# MANIFEST: files not included in this directory

This directory is a snapshot of the FDS-AMReX planning documents, made with
`sync_design_docs.sh` (kept in the project's local tools directory, not in this repository).
It contains every Markdown file of the working documents and every generated CSV table that is
referenced from a document and is smaller than 1000000 bytes. Machine-local absolute paths were
rewritten: paths into this repository are repo-relative, and paths on the development machine
are replaced by descriptions in parentheses, for example `(local build directory)`.

The files below were left out. The data tables are generated from the FDS/FireX source and input
files and can be regenerated; they are kept out of git because of their size. Documents that
cite them (mainly `inventory/README.md`) still name them, so those references do not resolve
inside this repository. The generator scripts live under `tools/inventory/` in the project's
working area and are not in this repository.
