**Ported** (D-072) means all of: a device run on record on real fields, within the class tolerance (bitwise, or at most 2 ulp for a libm kernel); reviewed by the kernel owner; and `tools/ci_checks.sh` (the four tools with `--strict`) passes. A libm kernel can be ported once the V&V Lead's ulp gate (the 2-ulp comparison of the device harness) exists and passes; the registry only records the tolerance. A device run alone does not make a kernel ported: the `Ported` column says `yes` only for kernels set there.
