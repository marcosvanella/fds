# FDS-AMR planning documents

Purpose: plan and track the refactor of NIST FDS (Fortran) onto AMReX block-structured adaptive mesh refinement (AMR), while keeping FDS's physics and verification record intact.

**Source pin.** All code references in these documents are to **FireX 36975d765f on branch `FDS-AMReX` (this repository)**: upstream FireX commit `36975d765f` (2026-09-24), from which the branch was cut. The branch was renamed from `AMReX` and is also on the project owner's fork as `marcosvanella/fds:FDS-AMReX` (github.com/marcosvanella/fds), at the same commit (D-037). The tree is strictly read-only until after the spec phase: no edits, no commits, no further branch operations (D-005, D-037; amended by D-044: the only commits allowed during the spec phase are documentation snapshots under `Manuals/FDS_AMReX_Design/`, generated by `tools/sync_design_docs.sh` and approved by the AMR Chief Architect; the first is `60ae2afb`, local, not yet pushed). Source citations still refer to `36975d765f`; a documentation snapshot does not move the pin. Line numbers are valid only for this commit. Under D-034 (owner decision, 2026-09-25), FireX is merged into `FDS-AMReX` daily once development starts; from then on V&V baselines and source line citations are re-pinned at each milestone, and every citation names the milestone pin it refers to (adopted plan pending V&V Lead confirmation, A-42; R-44). Until the first re-pin, every citation here refers to `36975d765f`. The earlier pin, `firemodels/fds` master `ce1f659` at `(local FDS master checkout)`, is superseded but kept as a read-only comparison copy. The inventory was re-anchored to FireX `36975d7` at checkpoint 2 (A-13 closed). The ADRs cite FireX lines (confirmed by the Chief Architect).

**Project chain.** The project owner → the project coordinator (all leads report here) → the leads (see charter.md §5; three joined on 2026-09-25: AMR Species & Combustion, AMR Radiation, AMR Solid Phase).

**Working environment.** One shared development machine (8-core CPU, 16 GB RAM, no GPU); gfortran 14.2 + OpenMPI 5 and Intel oneAPI installed. *Update 2026-09-25:* a Sep 23 reset wiped the apt packages. GNU 14.2 and OpenMPI 5.0.7 were reinstalled on 2026-09-25; Intel oneAPI was restored at the pre-reset versions under `/opt/intel/oneapi` on 2026-09-25 (ifx/icx 2026.1.1, Intel MPI 2021.18.1, MKL 2026.1; source `(local Intel third-party library tree)/env_oneapi.sh` before Intel builds; A-18 closed); FFTW 3.3.10 headers (`libfftw3-dev`, `libfftw3-mpi-dev`) were installed on 2026-09-25 (A-23 closed).
